Todas as telas, de ponta a ponta

Cada tela mapeada para a stack detectada no painel: Svelte (componentes e transições), Bootstrap + Bootstrap Icons (grid, forms, ícones), SweetAlert (modais), toastr (toasts), PHP (endpoints), PostgreSQL (dados), Cloudflare/HTTP 3 (edge, WAF), Mercado Pago Card Token e BitPay.

Os chips embaixo de cada tela dizem qual tecnologia entra ali e qual endpoint é chamado.
